Lista de todas as crianças

Pesquisa por nome ou usuário

Metas

Cada criança poderá criar metas financeiras.

Cada meta terá:

Nome

Valor desejado

Barra de progresso

Imagem opcional

Segurança

Utilizar o banco de dados do Lovable.

PINs armazenados com hash.

Sessões protegidas.

QR Code único para cada criança.

IDs únicos para todas as contas e transações.

Objetivo final

O Armoney deve parecer um banco digital infantil profissional, bonito e intuitivo, onde apenas o administrador (Arthur) gerencia as contas, cria crianças, realiza depósitos e saques, enquanto cada criança acessa apenas sua própria conta usando usuário e PIN, acompanha seu saldo, visualiza seu cartão virtual, QR Code, histórico e metas financeiras.
